# OSINT Поиск — Реальный поиск информации по ФИО

Десктопное приложение на Python, которое **реально собирает информацию** о человеке из открытых источников интернета.

![Python](https://img.shields.io/badge/Python-3.7+-blue?logo=python)
![No Dependencies](https://img.shields.io/badge/Dependencies-None-green)

---

## 📋 Что умеет приложение

Приложение **автоматически выполняет запросы** к реальным источникам и показывает результаты прямо в интерфейсе:

| Источник | Что ищет | Статус |
|----------|----------|--------|
| **Wikipedia** | Статьи о людях | ✅ Работает |
| **GitHub** | Пользователи и репозитории | ✅ Работает |
| **DuckDuckGo** | Веб-упоминания ФИО | ✅ Работает |
| **Google** | Веб-упоминания ФИО | ⚠️ Может блокировать |
| **Email** | Генерация возможных email | ✅ Работает |
| **Telegram** | Проверка профилей | ✅ Работает |
| **Instagram** | Проверка профилей | ✅ Работает |

## 🚀 Запуск

```bash

```

### Способ 2: Linux/macOS

```bash
python3 osint_search.py
```

### Способ 3: Двойной клик

Просто дважды кликните на файл `osint_search.py`.

## 🖥 Использование

1. Запустите приложение
2. Введите **Фамилию** и **Имя** (обязательно), **Отчество** (по желанию)
3. Нажмите кнопку **«НАЙТИ ИНФОРМАЦИЮ»** или клавишу **Enter**
4. Дождитесь завершения поиска (обычно 10-30 секунд)
5. Просмотрите результаты в текстовом поле
6. **Кликните на URL** — ссылка откроется в браузере

## ❗ Решение проблем

### Ошибка: "No module named 'tkinter'"

**Ubuntu/Debian:**
```bash
sudo apt-get install python3-tk
```

**Fedora:**
```bash
sudo dnf install python3-tkinter
```

**macOS:**
```bash
brew install python-tk
```

**Windows:**
Переустановите Python, отметив галочку "tcl/tk and IDLE"

### Google не выдаёт результаты
Google часто блокирует автоматические запросы. Это нормально — используйте DuckDuckGo как основной источник.

### Поиск занимает много времени
Приложение последовательно опрашивает все источники. Для ускорения можно прервать поиск и повторить с более точным ФИО.

## 🔧 Технические детали

- **Язык**: Python 3.7+
- **GUI**: tkinter (встроен в Python)
- **HTTP**: urllib.request (стандартная библиотека)
- **Парсинг**: html.parser, json (стандартная библиотека)
- **Зависимости**: Нет
- **Потоки**: threading (для неблокирующего поиска)
- **Платформы**: Windows, macOS, Linux
