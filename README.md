# OSINT Поиск — Поиск информации по ФИО

Веб-приложение для поиска информации о человеке по ФИО в открытых источниках интернета. Генерирует ссылки для поиска на поисковых системах, социальных сетях, профессиональных платформах и государственных сервисах.

## 📦 Установка

1. **Клонируйте репозиторий** (или скачайте архив):

```bash
git clone <url-репозитория>
cd <папка-проекта>
```

2. **Установите зависимости**:

```bash
npm install
```

Эта команда создаст папку `node_modules` и установит все необходимые пакеты из `package.json`.

## 🚀 Запуск в режиме разработки

Для запуска локального сервера разработки с горячей перезагрузкой:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```
http://localhost:5173
```

> 💡 Если порт 5173 занят, Vite автоматически предложит другой порт. Также можно указать порт вручную:
> ```bash
> npm run dev -- --port 3000
> ```

Сервер автоматически перезагружает страницу при изменении файлов исходного кода.

## 🏗 Сборка для продакшена

Для создания оптимизированной production-версии приложения:

```bash
npm run build
```

После выполнения команды готовые файлы появятся в папке `dist/`:

```
dist/
├── index.html          ← Главная страница
├── assets/
│   ├── index-*.css     ← Стили (минифицированные)
│   └── index-*.js      ← JavaScript (минифицированный)
```

Эти файлы можно разместить на любом статическом хостинге (Netlify, Vercel, GitHub Pages и т.д.).

---

## 👀 Предпросмотр production-сборки

После сборки можно запустить локальный сервер для проверки production-версии:

```bash
npm run preview
```

Это запустит статический сервер, который обслуживает файлы из папки `dist/`.

## ❗ Решение проблем

### Ошибка: "npm: command not found"
Установите Node.js с официального сайта https://nodejs.org. После установки перезапустите терминал.

### Ошибки при `npm install`
```bash
# Удалите кеш и зависимости, затем установите заново
rm -rf node_modules package-lock.json
npm cache clean --force
npm install
```

### Порт 5173 уже используется
```bash
# Укажите другой порт
npm run dev -- --port 3000
```

Или найдите и завершите процесс, занимающий порт:
```bash
# Linux/macOS
lsof -i :5173
kill -9 <PID>

# Windows
netstat -ano | findstr :5173
taskkill /PID <PID> /F
```

### Белый экран после сборки
Убедитесь, что файлы из папки `dist/` размещены в корне веб-сервера, а не в подпапке.

### Ошибки TypeScript
```bash
# Проверьте типы
npx tsc --noEmit
```
