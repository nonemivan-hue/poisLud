# OSINT Поиск — Поиск информации по ФИО

Десктопное приложение на Python для поиска информации о человеке по ФИО в открытых источниках интернета.

![Python](https://img.shields.io/badge/Python-3.7+-blue?logo=python)
![License](https://img.shields.io/badge/License-MIT-green)

---

## 📋 Описание

Приложение генерирует ссылки для поиска на 21+ открытых источниках:
- **Поисковые системы** — Google, Яндекс, Mail.ru, Bing, DuckDuckGo
- **Социальные сети** — ВКонтакте, Одноклассники, Facebook, Instagram, LinkedIn, Twitter/X, Telegram
- **Профессиональные платформы** — HeadHunter, Habr, GitHub
- **Государственные сервисы** — ФССП, ФНС, Госуслуги
- **Безопасность** — Have I Been Pwned
- **Дополнительный поиск** — поиск по email/телефону, поиск по фото

## 🚀 Запуск приложения

### Способ 1: Из командной строки

```bash
python osint_search.py
```

или (на Linux/macOS):

```bash
python3 osint_search.py
```

### Способ 2: Двойной клик

Просто дважды кликните на файл `osint_search.py` — он откроется в стандартном интерпретаторе Python.

### Способ 3: Создание ярлыка (Windows)

1. Создайте ярлык для файла `osint_search.py`
2. В свойствах ярлыка укажите:
   - **Объект**: `pythonw.exe путь\к\osint_search.py`
   - Использование `pythonw.exe` вместо `python.exe` скроет окно консоли

## ❗ Решение проблем

### Ошибка: "python: command not found"
Установите Python с официального сайта https://www.python.org/downloads

### Ошибка: "No module named 'tkinter'"
tkinter обычно включён в стандартную поставку Python. Если его нет:

**Ubuntu/Debian:**
```bash
sudo apt-get install python3-tk
```

**Fedora:**
```bash
sudo dnf install python3-tkinter
```

**macOS:**
```bash
brew install python-tk
```

**Windows:**
Переустановите Python, убедившись что отмечена галочка "tcl/tk and IDLE"

### Окно не появляется
Убедитесь, что у вас установлена графическая среда (X11/Wayland на Linux).
